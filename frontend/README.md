# Tildes — тренажёр казахского языка (MVP, фронтенд)

React 18 + Vite + React Router. Адаптивно: телефон (нижнее меню) и ноутбук (верхнее меню).
Светлая тема, акцент — фиолетовый.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Сначала запустите бэкенд (`backend/run.bat`), затем откройте http://localhost:5173. Чтобы открыть с телефона в той же Wi‑Fi сети — адрес `Network:` из консоли.

Сборка для продакшена: `npm run build` → папка `dist/`.

## Страницы

| Путь | Что там |
|---|---|
| `/login`, `/register` | Вход и регистрация по email и паролю. Без входа все страницы ниже перекидывают сюда |
| `/` | Пояснительная страница + выбор уровня внизу. Доступен только **B2**, остальные → «В разработке» |
| `/soon/:level` | «В разработке» с кнопкой «Назад» |
| `/home` | Главная: прогресс, рейтинг, блоки обучения (Карточки, Темы + 3 заглушки «Скоро») |
| `/cards` | Выбор темы для карточек, кнопка «Повторение» (все пройденные темы) |
| `/cards/:id`, `/cards/review` | Сессия карточек: «Я выучил» / «Учить ещё раз» |
| `/topics`, `/topics/:id` | Темы: Сөздер (слова) → Грамматика → Мәтін (текст) → Сұрақтар (тест) |
| `/rating` | Баллы, уровень, таблица лидеров, своё имя в рейтинге, правила начисления |

## Логика карточек (`src/store/srs.js`)

1. Основной проход — все слова темы по одному разу.
2. «Учить ещё раз» откладывает слово в **блок повторения в конце**.
3. В блоке повторения повторно «ещё раз» → слово возвращается через **8–12 карточек** (не каждые 5–7), либо в конец, если карточек меньше.
4. Режим «Повторение» берёт 20 слов из пройденных тем с весом:
   `вес = 1 + 2 × (сколько раз «ещё раз») − 0.5 × (сколько раз «выучил»)`, минимум 0.3.
   Трудные слова попадаются заметно чаще. Числа меняются в начале файла.

## Баллы (`src/store/progress.jsx`, объект `POINTS`)

«Я выучил» +10, «Учить ещё раз» +2, тема впервые +30, повтор +10, тест: +5 за каждый правильный ответ сверх лучшего результата.

## Данные и бэкенд

Сайт работает **через Django-бэкенд** (папка `backend`) — без него показывается экран «Нет связи с сервером».

- `src/api/client.js` — все запросы к API. Изменяющие запросы отправляются по очереди. Токен входа хранится в `localStorage` и уходит в заголовке `Authorization: Token …`. Если сервер ответил 401, сайт разлогинивает и открывает вход.
- `src/store/auth.jsx`, `src/pages/AuthPage.jsx` — вход и регистрация (`/login`, `/register`). Все остальные страницы закрыты `src/components/RequireAuth.jsx`: без входа сайт открывает `/login`. После первого входа ведёт к выбору уровня, потом сразу на главную.
- `src/store/content.jsx` — при старте загружает уровни и весь контент B2 (`GET /api/levels/b2/content/`).
- `src/store/progress.jsx` — прогресс и баллы с сервера (`/api/progress/`). Изменения показываются сразу, баллы сверяются с ответом сервера.
- Тест проверяет сервер (правильные ответы на фронт не приходят), колоду «Повторение» собирает сервер, таблица лидеров — настоящая.
- В разработке Vite проксирует `/api/*` на `http://127.0.0.1:8000` (`vite.config.js`). Для продакшен-сборки задайте адрес бэкенда в `VITE_API_URL` (см. `.env.example`).

## Как добавить новый блок обучения

В `src/pages/Home.jsx` перенесите элемент из массива `future` в `modes`, укажите `to`, добавьте страницу в `src/App.jsx`.
